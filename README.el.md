# aade-mydata-skills

[English](README.md)

Agent Skills που επιτρέπουν στο [Claude Code](https://claude.com/claude-code) να δουλεύει με το **myDATA της ΑΑΔΕ** (ηλεκτρονικά βιβλία):

- **Ανάγνωση βιβλίων**: παραστατικά που σας έστειλαν προμηθευτές, παραστατικά που εκδώσατε, σύνολα εσόδων και εξόδων ανά αντισυμβαλλόμενο, με αυτόματη τμηματική λήψη. Έξοδος σε JSON ή CSV.
- **Χαρακτηρισμός εξόδων**: το Claude προτείνει χαρακτηρισμούς (κωδικούς E3 και ΦΠΑ) για τα αχαρακτήριστα παραστατικά, τους ελέγχει με τον επίσημο πίνακα συνδυασμών της ΑΑΔΕ, σας δείχνει ακριβώς τι θα σταλεί και στέλνει μόνο αφού πείτε «ναι».
- **Συμφωνία (reconciliation)**: αντιστοίχιση του myDATA με εξαγωγή CSV από ERP, λογιστικό πρόγραμμα ή τράπεζα, με βάση ΜΑΡΚ, ΑΦΜ, ημερομηνία και ποσό, και λίστα με ό,τι λείπει ή διαφέρει σε κάθε πλευρά.

Απευθύνεται σε ελληνικές επιχειρήσεις και λογιστές. Η έκδοση 1 διαβάζει και χαρακτηρίζει· δεν εκδίδει ούτε ακυρώνει παραστατικά. **Από προεπιλογή μιλά με το δοκιμαστικό περιβάλλον.**

Διαβάστε το άρθρο: [Δωρεάν, ανοιχτός κώδικας: βοηθός AI για το myDATA](https://eigen.gr/el/insights/mydata-ai-skills-dorean/).

> Δεν σχετίζεται με την ΑΑΔΕ ούτε έχει την έγκρισή της. Δεν αποτελεί φορολογική συμβουλή: ο λογιστής σας πρέπει να ελέγχει τους χαρακτηρισμούς πριν σταλούν στο παραγωγικό περιβάλλον.

## Εγκατάσταση

**1. Προσθέστε το skill** (με έναν από τους δύο τρόπους):

```bash
# ως plugin του Claude Code
/plugin marketplace add eigen-lp/aade-mydata-skills
/plugin install aade-mydata@eigen-lp
```

```bash
# ή αντιγράφοντας τον φάκελο του skill
git clone https://github.com/eigen-lp/aade-mydata-skills
cp -r aade-mydata-skills/skills/aade-mydata ~/.claude/skills/
```

**2. Πάρτε δοκιμαστικά διαπιστευτήρια** από <https://mydata-dev-register.azurewebsites.net> και δώστε τα όταν το Claude Code ζητήσει τις ρυθμίσεις του plugin (όνομα χρήστη, subscription key, περιβάλλον `test`). Το κλειδί κρύβεται κατά την πληκτρολόγηση και φυλάσσεται στον ασφαλή χώρο διαπιστευτηρίων του συστήματός σας, ποτέ στη συνομιλία. Τα αλλάζετε αργότερα από `/plugin` → aade-mydata → configure.

Αντιγράψατε τον φάκελο του skill αντί να εγκαταστήσετε το plugin; Βάλτε τα στο shell σας ή σε αρχείο εκτός git που δίνετε με `--env-file`:

```bash
export MYDATA_USER_ID="το-δοκιμαστικό-όνομα-χρήστη"
export MYDATA_SUBSCRIPTION_KEY="το-δοκιμαστικό-subscription-key"
```

**3. Ανοίξτε νέα συνεδρία του Claude Code** και ζητήστε, για παράδειγμα:

- «Έλεγξε τη ρύθμιση του myDATA.»
- «Ποια τιμολόγια προμηθευτών του Οκτωβρίου είναι ακόμη αχαρακτήριστα; Πρότεινε χαρακτηρισμούς.»
- «Συμφώνησε τις αγορές Οκτωβρίου στο myDATA με το `purchases.csv`.»

Απαιτείται Python 3.9 ή νεότερη (μόνο η standard library, δεν χρειάζεται `pip install`).

**Cowork:** το ίδιο plugin λειτουργεί και εκεί. Προσθέστε το από **Customize > Plugins** (marketplace `eigen-lp/aade-mydata-skills` ή ανέβασμα του zip της έκδοσης), επιτρέψτε πρόσβαση δικτύου στα `mydatapi.aade.gr` και `mydataapidev.aade.gr` και κρατήστε τα διαπιστευτήρια σε αρχείο `.env` σε φάκελο που μοιράζεστε με την εργασία. Λεπτομέρειες στο [setup.md](skills/aade-mydata/references/setup.md#using-it-in-cowork-or-chat).

## Παραγωγικό περιβάλλον

Το παραγωγικό περιβάλλον έχει ξεχωριστά διαπιστευτήρια, που δημιουργούνται αφού συνδεθείτε με κωδικούς TAXISnet στο <https://www1.aade.gr/saadeapps2/bookkeeper-web> («Φόρμα εγγραφής στο myDATA REST API»). Ορίστε `MYDATA_ENV=prod` ή δώστε `--env prod`. Η ανάγνωση λειτουργεί το ίδιο· η αποστολή χαρακτηρισμών στην παραγωγή χρειάζεται επιπλέον `--yes-production` στην εντολή `send`, που το Claude προσθέτει μόνο όταν επιβεβαιώσετε ρητά ότι πρόκειται για τα πραγματικά σας βιβλία. Μπορείτε να κρατάτε τα διαπιστευτήρια κάθε περιβάλλοντος σε αρχείο εκτός git και να το δίνετε με `--env-file .env.prod`. Οι λογιστές που ενεργούν για πελάτη προσθέτουν `--entity <ΑΦΜ πελάτη>`.

## Ασφάλεια

- Τα κλειδιά μένουν εκτός συνομιλίας: στις ρυθμίσεις του plugin (ασφαλής χώρος διαπιστευτηρίων), σε μεταβλητές περιβάλλοντος ή σε αρχείο `--env-file` εκτός git. Το script δεν τα εμφανίζει ποτέ και το skill απαγορεύει στο Claude να τα ζητήσει στη συνομιλία.
- **Οι αναγνώσεις τρέχουν χωρίς ερώτηση· οι εγγραφές ρωτούν πάντα.** Το skill προεγκρίνει τις εντολές ανάγνωσης (`check`, `docs`, `transmitted`, `income`, `expenses`, `classify`, `reconcile`). Η μόνη εγγραφή, το `send`, δεν είναι προεγκεκριμένη: το Claude Code σας δείχνει την εντολή και ζητά άδεια πριν τρέξει.
- Το `classify` είναι δοκιμαστική εκτέλεση (dry run): ελέγχει την πρόταση (κωδικούς, ποσά, συνδυασμούς τύπου παραστατικού, κατηγορίας και E3 της ΑΑΔΕ) και τυπώνει πίνακα, το ακριβές XML και έναν κωδικό επιβεβαίωσης. Το Claude πρέπει να σας δείξει τον πίνακα και να πάρει ρητό «ναι»· το `send` δέχεται μόνο τον αντίστοιχο κωδικό, οπότε στην ΑΑΔΕ φτάνει ακριβώς ό,τι εγκρίνατε.
- Η αποστολή στην παραγωγή απαιτεί τη σημαία `--yes-production`.
- Αν ξαναστείλετε χαρακτηρισμό για το ίδιο παραστατικό, αντικαθιστά τον προηγούμενο στο myDATA.

Περισσότερα στο [SECURITY.md](SECURITY.md).

## Δεδομένα και ιδιωτικότητα

Το plugin επικοινωνεί μόνο με το API του myDATA της ΑΑΔΕ (`mydataapidev.aade.gr` για δοκιμές, `mydatapi.aade.gr` για παραγωγή): στέλνει τα δικά σας διαπιστευτήρια και, μετά την έγκρισή σας, τους χαρακτηρισμούς που επιβεβαιώσατε. Δεν έχει δικό του server, analytics ή telemetry· η Eigen δεν λαμβάνει τίποτα. Ένα SessionStart hook περνά τις αποθηκευμένες ρυθμίσεις του plugin στη συνεδρία ώστε να τις διαβάζει το script, χωρίς να τυπώνει τίποτα. Αρχεία γράφονται μόνο όπου ζητάτε με `--out`. Δείτε την [πολιτική απορρήτου](PRIVACY.md) και τους [όρους χρήσης](TERMS.md) (στα αγγλικά).

## Πηγές

Βασίζεται στην επίσημη «Τεχνική περιγραφή διεπαφών REST API για διαβίβαση & λήψη δεδομένων από χρήστες ERP», **έκδοση 2.0.2**, στα αντίστοιχα XSD και στο αρχείο «Συνδυασμοί χαρακτηρισμών» v2.0.2 της ΑΑΔΕ, όλα στη σελίδα <https://www.aade.gr/mydata/tehnikes-prodiagrafes-ekdoseis-mydata>. Τα αρχεία της ΑΑΔΕ δεν αναδιανέμονται εδώ· το `tools/build_combinations.py` ξαναχτίζει τον πίνακα συνδυασμών από το επίσημο αρχείο.
